「セラピストノート 施術記録」サポート

最終更新：2026年8月8日

iPhone アプリ「セラピストノート 施術記録」の使い方とお問い合わせのページです。お客様ごとに、身体の状態・施術内容・好み・会話を記録しておくアプリです。

記録したデータはどこにありますか

お使いの iPhone の中だけに保存されます。開発者を含む第三者のサーバーには送信されません。詳しくはプライバシーポリシーをご覧ください。

機種変更するときは

いまの端末で、設定タブ →「データの控え」→［控えを書き出す］。出てきた共有シートから、ファイルアプリやメールなど、新しい端末で取り出せる場所に保存します。

新しい端末では、設定タブ →「データの控え」→［控えから読み込む］で、保存したファイルを選びます。読み込むと、その端末にあったお客様の情報は控えの内容に置き換わります。

無料で使える範囲は

お客様10人までは無料です。11人目を登録するときにプレミアム（サブスクリプション）の案内が出ます。プレミアムにすると人数の上限がなくなります。7日間は無料で試せます。

施術記録の件数・データの書き出し・アプリのロックには、無料・プレミアムの違いはありません。

解約したいときは

iPhone の「設定」アプリ → いちばん上の名前 →「サブスクリプション」→「セラピストノート」から解約します。アプリの中からは解約できません。

無料期間の途中で解約すると、期間の終わりまで使えます。

購入したのに人数の上限が外れないときは

設定タブ →「ご利用プラン」→［購入を復元］を押します。プレミアムの案内画面にも同じボタンがあります。

購入したときと同じ Apple ID でサインインしているか、あわせてご確認ください。

アプリのロックが解除できないときは

Face ID / Touch ID を認識しないときは、そのまま端末のパスコードで開けます。

ロックが不要であれば、設定タブ →「アプリのロック」でオフにできます。

お客様や記録を消したいときは

お客様の削除は、お客様詳細の右上［編集］→ いちばん下の［このお客様を削除］から。そのお客様の施術記録も一緒に消えます。

すべて消すときは、設定タブ →「データの削除」から。データは端末内にのみあるため、消すと元に戻せません。

できないこと

  • 予約の管理・売上や会計の計算はできません。次回の来店予定は、日付のメモとして持つだけです。
  • 複数の端末での同期、スタッフ間での共有はできません。
  • 本アプリは施術の記録を行うツールであり、医療行為・診断を行うものではありません。
